# ru-geocoder

Автор: Миллер Михаил

Название задачи: geocoder

Геокодер для российских адресов на базе OSM. В основе лежит виртуальная таблица **SQLite FTS5**.


Вход: адрес в свободной форме
Выход: координаты и полный адрес

### Одиночный режим (Single Mode)
Поиск координат для одной адресной строки:
```bash
python3 src/cli.py -a "г. Москва, ул. Ленина, д. 15"
```

Вывод:
```
{
  "region": "московская область",
  "city": "москва",
  "street": "ленина",
  "house": "15",
  "lat": 55.7558,
  "lon": 37.6173
}
```
### Пакетный режим (Batch Mode)

Обработка текстового файла с адресами (один адрес на строку).
Результаты сохраняются в формате JSON Lines (.jsonl).

```bash
python3 src/cli.py -i input_addresses.txt -o output_results.jsonl
```

### Режим отладки (Debug Mode)

Для вывода расширенных системных логов, отслеживания этапов парсинга и трейсбэков используйте флаг --debug

```bash
python3 src/cli.py -a "новосибирск" --debug
```
`DBClient` - Прямое взаимодействие с базой данных SQLite.

`Parser` - Парсинг входной адресной строки на токены (регион, город, улица, дом).

`Engine` - Принимает сырую строку, использует `Parser` для извлечения токенов и форимрует запрос для `DBClient`

`CLI` - Интерфейс командной строки, работает на `argparse`, принимает флаги `-a, -i, -o, --debug`
Перенаправляет потоки данных: в одиночном режиме выводит результат в stdout, в пакетном — читает и пишет файлы

Если входной файл input_addresses.txt выглядит так:

```Plaintext
Москва, Тверская 12
Новосибирск, Ленина 4
Казань, Баумана 10
```

То итоговый выходной файл output_results.jsonl будет выглядеть следующим образом:

```JSONL
{"query": "Москва, Тверская 12", "status": "FOUND", "region": "москва", "city": "москва", "street": "тверская", "house": "12", "lat": 55.7595, "lon": 37.6111}
{"query": "Новосибирск, Ленина 4", "status": "FOUND", "region": "новосибирская область", "city": "новосибирск", "street": "ленина", "house": "4", "lat": 55.0282, "lon": 82.9234}
{"query": "Казань, Баумана 10", "status": "NOT_FOUND", "region": null, "city": null, "street": null, "house": null, "lat": null, "lon": null}
```
