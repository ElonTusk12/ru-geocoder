# ru-geocoder

**Автор:** Миллер Михаил  
**Название проекта:** ru-geocoder

Высокопроизводительный геокодер для российских адресов на базе данных OpenStreetMap (OSM). В качестве основного поискового движка используется **Tantivy** (Rust) с нечётким поиском (Fuzzy Search / опечатки) и весовым ранжированием (BM25). В качестве запасного механизма (fallback) поддерживается полнотекстовый поиск через виртуальную таблицу **SQLite FTS5** с ранжированием по алгоритму **BM25**.

---

## Основные возможности

- **Высокоскоростной полнотекстовый поиск (Tantivy):** мгновенный отбор адресов благодаря поисковому движку на Rust с памятью mmap и весами полей (город, улица, организация, дом, регион).
- **Нечёткий поиск и устойчивость к опечаткам (Fuzzy Search):** автоматический переход на поиск по расстоянию Левенштейна в Tantivy при опечатках в запросе.
- **Отказоустойчивость (SQLite FTS5 + BM25):** при отсутствии построенного индекса Tantivy геокодер автоматически переключается на встроенный поиск по SQLite с функцией `bm25(...)`.
- **Группировка организаций (`orgs`):** если по одному физическому адресу зарегистрировано несколько организаций, они объединяются в один адресный результат со списком всех найденных организаций.
- **Нормализованный рейтинг релевантности (`similarity_score`):** расчет относительной уверенности совпадения от 0 до 100%.
- **Единое форматирование адресов (`format_address`):** централизованная сборка аккуратных человекочитаемых строк адреса без дублирования.
- **Два режима работы (CLI):** одиночный геокодинг адреса через консоль и пакетная потоковая обработка файлов (`.jsonl`).
- **Веб-интерфейс и REST API (FastAPI):** интерактивная карта с Leaflet.js и готовые HTTP-эндпоинты.
- **JSON / JSONL вывод:** удобная машиночитаемая структура ответа.

## Установка и подготовка данных

Требуется **Python 3.10+**.

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Инициализация базы данных и построение индекса:
- Импорт адресных данных OpenStreetMap в SQLite:
```bash
python3 data/import_data.py
```
- Построение быстрого индекса Tantivy (при первом запуске геокодера индекс также может собраться автоматически при наличии SQLite базы):
```bash
python3 data/build_tantivy_index.py
```

## Использование (CLI)

Запуск осуществляется как модуль: `python3 -m src.cli [параметры]`.

### Доступные флаги

| Флаг | Полное имя | Описание |
|---|---|---|
| `-a` | `--address` | Одиночный адрес в свободной форме для геокодирования |
| `-i` | `--input` | Путь к входному текстовому файлу со списком адресов (пакетный режим) |
| `-o` | `--output` | Путь к выходному файлу для сохранения результатов (формат `.jsonl`) |
| `-n` | `--number` | Максимальное количество вариантов адресов в выдаче (по умолчанию: `1`) |
| `-d` | `--db` | Пользовательский путь к базе данных SQLite (по умолчанию: `data/geocoder.db`) |
| | `--debug` | Режим отладки (вывод полного трейсбэка ошибок) |

---

### 1. Одиночный режим (Single Mode)

Поиск координат и информации для одной адресной строки:

```bash
python3 -m src.cli -a "краснодарский край, березанская, ул. Ленина, д. 28"
```

**Пример вывода (JSON):**
```json
[
  {
    "format_address": "краснодарский край, г. березанская, ул. улица ленина, д. 28",
    "region": "краснодарский край",
    "city": "березанская",
    "street": "улица ленина",
    "house": "28",
    "orgs": [
      "школа №3"
    ],
    "lat": 45.7052916,
    "lon": 39.6002208,
    "similarity_score": 100.0
  }
]
```

Если по адресу находится несколько организаций, все они будут собраны в списке `"orgs"`.

Для получения нескольких подходящих вариантов адресов используйте флаг `-n`:
```bash
python3 -m src.cli -a "березники, пр. Ленина" -n 3
```

---

### 2. Пакетный режим (Batch Mode)

Обработка текстового файла с адресами (один адрес на строку). Результаты построчно сохраняются в формате JSON Lines (`.jsonl`).

```bash
python3 -m src.cli -i input_addresses.txt -o output_results.jsonl
```

**Пример входного файла (`input_addresses.txt`):**
```text
Москва, Тверская 12
краснодарский край, березанская, ул. Ленина, д. 28
Несуществующий адрес 99999
```

**Пример выходного файла (`output_results.jsonl`):**
```json
{"initial_address": "Москва, Тверская 12", "status": "success", "format_address": "московская область, г. москва, ул. тверская, д. 12", "address_components": {"region": "московская область", "city": "москва", "street": "тверская", "house": "12", "orgs": []}, "lat": 55.7595, "lon": 37.6111}
{"initial_address": "краснодарский край, березанская, ул. Ленина, д. 28", "status": "success", "format_address": "краснодарский край, г. березанская, ул. улица ленина, д. 28", "address_components": {"region": "краснодарский край", "city": "березанская", "street": "улица ленина", "house": "28", "orgs": ["школа №3"]}, "lat": 45.7052916, "lon": 39.6002208}
{"initial_address": "Несуществующий адрес 99999", "status": "not_found"}
```

Возможные статусы строки в пакетном режиме:
- `"success"` — адрес успешно найден;
- `"not_found"` — совпадений в базе данных не найдено;
- `"parse_error"` — строка адреса пуста или не содержит распознаваемых токенов.

---

### 3. Режим отладки (Debug Mode)

Для анализа ошибок и вывода расширенных трейсбэков используйте флаг `--debug`:

```bash
python3 -m src.cli -a "новосибирск" --debug
```

#### Коды возврата CLI (Exit Codes):
- `0` — Успешное выполнение (`Success`);
- `1` — Обработанная ошибка геокодера или адрес не найден (`Handled Error`);
- `2` — Критическая или непредвиденная ошибка (`Critical Error`).

## Веб-интерфейс и API (FastAPI)

Проект включает в себя веб-приложение и REST API на базе **FastAPI** с интерактивной картой на **Leaflet.js** (`static/index.html`), где результаты поиска отображаются прямо под картой.

### Запуск веб-сервера

Для запуска сервера разработки через `uvicorn`:

```bash
uvicorn src.web.app:app --reload
```

После запуска перейдите в браузере по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000).

### API Endpoints

- `GET /` — возвращает HTML-интерфейс с картой и поиском.
- `GET /api/geocode` — REST API для геокодирования адресов.
  - **Query-параметры:**
    - `address` (string) — искомый адрес в свободной форме.
    - `limit` (int, опционально, по умолчанию `1`) — количество возвращаемых вариантов.
  - **Пример запроса:**
    ```bash
    curl "http://127.0.0.1:8000/api/geocode?address=Москва,%20Тверская%207&limit=1"
    ```
  - **Пример ответа (JSON):**
    ```json
    {
      "status": "success",
      "data": [
        {
          "format_address": "московская область, г. москва, ул. тверская, д. 7",
          "region": "московская область",
          "city": "москва",
          "street": "тверская",
          "house": "7",
          "orgs": [],
          "lat": 55.7595,
          "lon": 37.6111,
          "similarity_score": 100.0
        }
      ]
    }
    ```

## Архитектура проекта

```text
ru-geocoder/
├── data/
│   ├── geocoder.db              # Основная база данных SQLite с FTS5 таблицей адресов
│   ├── geocoder_tantivy/        # Директория с полнотекстовым индексом Tantivy
│   ├── import_data.py           # Скрипт импорта данных OSM (.pbf / .geojson) в SQLite
│   └── build_tantivy_index.py   # Скрипт построения индекса Tantivy из SQLite
├── src/
│   ├── core/
│   │   ├── db_client.py         # DBClient: доступ к SQLite FTS5 (BM25 fallback) и открытие Tantivy
│   │   ├── tantivy_index.py     # Поиск через Tantivy (веса полей, двухэтапный exact/fuzzy search)
│   │   ├── formatter.py         # format_address: единое форматирование читаемых строк адреса
│   │   ├── parser.py            # AddressParser: очистка стоп-слов и токенизация адреса
│   │   └── engine.py            # GeocoderEngine: координация поиска, нормализация скоринга и группировка
│   ├── web/
│   │   └── app.py               # FastAPI приложение и REST API эндпоинты
│   ├── cli.py                   # Консольный интерфейс argparse
│   └── exceptions.py            # Пользовательские исключения проекта
├── static/
│   └── index.html               # Веб-интерфейс с поиском и интерактивной картой (Leaflet.js)
├── tests/                       # Набор модульных и интеграционных тестов (pytest)
│   ├── test_cli.py
│   ├── test_db_client.py
│   ├── test_engine.py
│   ├── test_formatter.py
│   ├── test_parser.py
│   └── test_data/
│       ├── geocoder_test.db     # Тестовая база данных SQLite
│       └── init_test_db.py      # Скрипт инициализации тестовой БД
├── requirements.txt             # Зависимости проекта
└── README.md
```

- **`AddressParser`**: очищает входную строку от пунктуации и стоп-слов (`г.`, `ул.`, `д.`, `обл.` и т.д.), извлекая чистые токены для поисковых движков.
- **`Tantivy Index (`tantivy_index.py`)`**: выполняет быстрый поиск по индексу с бустингом полей (`city: 15.0`, `street: 5.0`, `org: 3.0`, `house: 2.0`, `region: 1.0`), а при отсутствии точных совпадений переключается на нечёткий поиск (расстояние Левенштейна).
- **`DBClient`**: управляет подключением к SQLite и открытием Tantivy-индекса. При недоступности Tantivy производит поиск через метод `search_bm25` в FTS5-таблице `addresses` с формулой ранжирования `bm25(...)`.
- **`Formatter (`formatter.py`)`**: предоставляет единую функцию `format_address`, устраняя дублирование логики форматирования адреса между базой данных, Tantivy и движком.
- **`GeocoderEngine`**: верхнеуровневый координатор: связывает парсер с базой/Tantivy, вычисляет нормализованный процент схожести (`similarity_score`) и группирует несколько организаций по одному адресу в массив `orgs`.
- **`FastAPI App (`src/web/app.py`)`**: предоставляет REST API (`/api/geocode`) и раздает статический веб-интерфейс.
- **`Web UI (`static/index.html`)`**: пользовательский веб-интерфейс с Leaflet.js, отображением маркеров на карте и списком кандидатов.
- **`CLI`**: обрабатывает аргументы командной строки, форматирует вывод и управляет одиночным и пакетным режимами работы.
